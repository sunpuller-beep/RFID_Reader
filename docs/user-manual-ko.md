# RFID-Reader 사용자 매뉴얼

## 1. 앱 개요

RFID-Reader 앱은 RFID sled를 연결한 뒤 현장에서 태그를 스캔하고, 태그의 EPC/TID/USER 데이터를 읽어 CSV 파일로 저장하기 위한 앱입니다.

일반 사용자는 메인 화면의 기본 메뉴만 사용합니다. RFID 송신 출력, 안테나, RF 모드 같은 장비 동작 설정은 관리자 메뉴에 분리되어 있습니다.

## 2. 메인 화면 메뉴

앱을 실행하면 메인 화면에 다음 메뉴가 표시됩니다.

| 메뉴 | 용도 | 사용 시점 |
| --- | --- | --- |
| CONNECTIVITY | RFID sled 연결/해제 및 연결 상태 확인 | 태그 스캔 전에 먼저 사용 |
| SCAN | 태그 스캔, 태그 데이터 읽기, CSV 저장 | 일반 작업의 기본 화면 |
| BATTERY | 배터리 상태 확인 | 작업 전/중 장비 상태 점검 |
| INFORMATION | 장비 및 앱 정보 확인 | 버전, 시리얼 번호, sled 종류 확인 |

### 기본 사용 순서

1. `CONNECTIVITY`에서 RFID sled가 연결되어 있는지 확인합니다.
2. 메인 화면으로 돌아와 `SCAN`을 선택합니다.
3. 현장명 또는 위치명을 입력한 뒤 `SET PLACE`를 누릅니다.
4. `START SCAN`을 눌러 태그 수집을 시작합니다.
5. 작업 구역을 이동하며 태그를 수집합니다.
6. `STOP SCAN`을 눌러 스캔을 멈춥니다.
7. `READ TAG DATA`를 눌러 수집된 태그의 TID/USER 데이터를 읽습니다.
8. `SAVE CSV`를 눌러 결과를 CSV 파일로 저장합니다.
9. 새 작업을 시작할 때는 `CLEAR`로 현재 목록을 초기화합니다.

## 3. SCAN 화면 사용법

### 화면 표시 항목

| 항목 | 의미 |
| --- | --- |
| Place | 현재 작업 장소 또는 구역명 |
| Found | 스캔으로 발견한 고유 EPC 태그 수 |
| Read | TID/USER 데이터 읽기에 성공한 태그 수 |
| Failed | 데이터 읽기에 실패한 태그 수 |
| File path | CSV 저장 후 파일 저장 위치 |
| Tag list | 현재 수집된 태그 목록 |

### 버튼 설명

| 버튼 | 기능 |
| --- | --- |
| SET PLACE | 입력한 장소명을 현재 스캔 작업에 적용 |
| START SCAN | RFID 태그 수집 시작 |
| STOP SCAN | RFID 태그 수집 중지 |
| READ TAG DATA | 발견된 태그의 TID/USER 메모리 읽기 |
| SAVE CSV | 결과를 CSV 파일로 저장 |
| CLEAR | 현재 스캔 결과 초기화 |

### CSV 저장 내용

CSV 파일에는 기본적으로 다음 데이터가 저장됩니다.

```csv
epc,tid,user,status,error
```

| 컬럼 | 의미 |
| --- | --- |
| epc | 태그의 EPC 값 |
| tid | 태그의 TID 메모리 값 |
| user | 태그의 USER 메모리 값 |
| status | 처리 결과 |
| error | 실패 사유가 있을 때 기록 |

## 4. 관리자 메뉴 진입 방법

관리자 메뉴는 일반 메인 화면에 바로 표시되지 않습니다. 아래 순서로 진입합니다.

1. 메인 화면에서 `INFORMATION` 메뉴를 길게 누릅니다.
2. 화면에 `Admin menu enabled` 메시지가 표시되는지 확인합니다.
3. 화면 왼쪽에서 오른쪽으로 밀거나, 상단 왼쪽의 드로어 버튼을 눌러 좌측 메뉴를 엽니다.
4. 좌측 메뉴에 관리자 항목이 추가되어 표시됩니다.

관리자 메뉴를 숨기려면 메인 화면의 `INFORMATION`을 다시 길게 누릅니다. 이때 `Admin menu hidden` 메시지가 표시됩니다.

## 5. 관리자 메뉴 구성

| 메뉴 | 용도 | 주의사항 |
| --- | --- | --- |
| Admin - RF Config | RFID 무선 설정 변경 | 읽기 거리, 성능, 법규 설정에 영향 |
| Admin - RF Selection | 특정 태그 조건 선택 설정 | 잘못 설정하면 일부 태그만 읽힐 수 있음 |
| Admin - SD Function | sled 장비 기능 설정 | 트리거, 절전, 부저, LED, 펌웨어 관련 |
| Admin - Inventory | 고급 인벤토리/진단 화면 | 테스트 및 문제 분석용 |

관리자 메뉴는 장비 동작을 바꿀 수 있으므로 현장 일반 작업 중에는 필요한 항목만 변경해야 합니다.

## 6. 태그 읽기 범위 조절

카탈로그에서 확인한 최대 읽기 거리, 예를 들어 최대 6m 같은 값은 장비와 태그가 좋은 조건에 있을 때 가능한 최대 성능입니다. 앱에서 `6m`, `3m`처럼 거리를 직접 입력하는 옵션은 없습니다.

현재 앱에서 읽기 범위에 가장 직접적으로 영향을 주는 설정은 관리자 메뉴의 RF 송신 출력입니다.

### RFPower 설정 위치

1. 관리자 메뉴를 활성화합니다.
2. 좌측 드로어 메뉴에서 `Admin - RF Config`를 선택합니다.
3. `RFPower` 입력 항목을 찾습니다.
4. 값을 입력한 뒤 `Set RFPower`를 누릅니다.
5. 현재 값을 확인하려면 `Get RFPower`를 누릅니다.

### RFPower 값

| 항목 | 값 |
| --- | --- |
| 설정 범위 | 5 ~ 30 |
| 값이 낮을 때 | 읽기 범위가 줄어들 수 있음 |
| 값이 높을 때 | 읽기 범위가 늘어날 수 있음 |

일반적으로 RFPower 값이 높을수록 더 멀리 있는 태그를 읽을 가능성이 커집니다. 다만 실제 읽기 거리는 다음 조건에 따라 달라집니다.

- 태그 종류와 크기
- 태그 부착 재질
- 태그 방향
- 주변 금속 또는 액체
- sled 배터리 상태
- 주변 RF 간섭
- 국가/지역별 RF 출력 제한

따라서 RFPower는 “거리 설정”이 아니라 “송신 출력 설정”으로 이해해야 합니다.

## 7. 권장 운영 방법

일반 스캔 작업에서는 다음 순서를 권장합니다.

1. `BATTERY`에서 배터리 상태를 확인합니다.
2. `CONNECTIVITY`에서 sled 연결 상태를 확인합니다.
3. `SCAN`에서 태그를 수집하고 데이터를 저장합니다.
4. 태그가 너무 멀리서 읽히거나 너무 가까이서만 읽히는 경우에만 관리자 메뉴에서 `RFPower`를 조정합니다.
5. RFPower 변경 후에는 같은 위치에서 테스트 스캔을 수행해 실제 읽기 범위를 확인합니다.

## 8. 주의사항

- RFPower를 최대로 설정해도 항상 6m까지 읽히는 것은 아닙니다.
- RFPower를 높이면 원하지 않는 주변 태그까지 읽힐 수 있습니다.
- RFPower를 낮추면 가까운 태그만 읽게 되어 누락이 생길 수 있습니다.
- `Admin - RF Selection` 설정이 남아 있으면 특정 조건의 태그만 읽힐 수 있습니다.
- 장비 동작이 이상하면 관리자 설정 변경 이력을 확인한 뒤 필요 시 기본 설정으로 복구해야 합니다.
